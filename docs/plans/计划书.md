# FD-LLM 复现计划

本计划按模块推进复现工作。各模块使用明确的数据与结果接口，具体实现方案、参数和实验设置在进入相应阶段时确定并记录。

| 阶段 | 对应模块 | 实现内容 | 验证目标 |
| --- | --- | --- | --- |
| 0. 项目规划 | `configs/`、项目结构 | 明确代码架构、模块职责、接口和配置管理方式 | 模块依赖清晰，输入输出约定一致 |
| 1. 数据处理 | `data/preprocessing/`、数据集 | 完成 CWRU 数据读取、切窗、划分、标准化和类别文本描述 | 样本数、形状与标签正确；核实采样率、通道、数据来源及划分方式 |
| 2. 模态对齐 | `src/alignment/` | 实现时序特征提取、文本编码和对比学习 | 训练过程正常，损失下降，数据与文本特征能够对齐 |
| 3. LLM 诊断 | `src/diagnosis/` | 实现模糊语义嵌入、提示构造、Vicuna 接入与 LoRA 微调 | 前向传播、梯度更新和诊断文本生成符合预期 |
| 4. 基线模型 | `baselines/` | 实现 CNN、ResNet18、Transformer 等对照模型 | 与 FD-LLM 使用一致的数据划分和评价口径 |
| 5. 实验结果评估 | `src/evaluation/`、`experiments/`、`outputs/` | 汇总分类指标、重复实验结果及论文对照 | 结果可复现，指标计算正确，差异及实验条件有记录 |

数据处理为后续模型提供共同输入；模态对齐的结果供 LLM 诊断使用；基线模型与 FD-LLM 的结果最终进入同一评估流程。
